# Incidents and the rules they left

A chronological index of the incidents behind Edward's rules: what happened, the rule or code it produced, and where the longer story lives. Every incident happened on the reference install — one person's Edward on one Mac, running for months before this release — so the numbers are that install's. When a rule elsewhere seems odd, look here for its date first.
